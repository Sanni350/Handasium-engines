Materials & Cover
αcc is National-Annex-dependent (0.85 UK, up to 1.0 elsewhere). φef=0 excludes creep amplification of second-order effects (Cl 5.8.4) — set a realistic value for genuinely slender columns.
βdns = ratio of max factored sustained axial load to max factored total axial load, used in the EI stiffness reduction (Cl 6.6.4.4.4). Tied columns only — spiral confinement is a later phase.

Bracing, End Conditions & Height
End conditions 1–3 per Table 3.19 (braced) / 3.20 (unbraced), Cl 3.8.1.6.2. Condition 4 only as top=4/bottom=1, unbraced.
K1/K2 are relative end flexibilities (Annex H) — the ratio of the column's own stiffness to the combined stiffness of connecting beams at that end. Use 0.1 for an idealised near-rigid connection (not 0 — perfectly rigid is unrealistic, Cl 5.8.3.2(3)); use larger values (≈1–5) for more flexible connections such as a pinned or lightly-framed end.
ψA/ψB are relative end stiffness ratios (Cl 6.2.5, Fig R6.2.5.1) — same concept as EC2's K1/K2, different formula. Use small values (~0.5–1) for typical framed connections, larger for more flexible ends.
